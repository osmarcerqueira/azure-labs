# Serviços de Computação do Azure

## Objetivo

Conhecer as principais opções de computação oferecidas pelo Microsoft Azure e entender quando utilizar cada uma delas.

---

## Principais serviços

### Azure Virtual Machines

Máquinas virtuais sob demanda.

Ideal para:

- aplicações legadas
- Active Directory
- SQL Server
- Linux
- Windows

---

### Azure App Service

Hospedagem de aplicações Web sem gerenciar servidores.

Ideal para:

- APIs
- Sites
- Aplicações Web

---

### Azure Functions

Computação Serverless baseada em eventos.

Ideal para:

- automações
- integrações
- processamento de arquivos

---

### Azure Container Instances (ACI)

Execução rápida de containers sem Kubernetes.

---

### Azure Kubernetes Service (AKS)

Gerenciamento de containers em grande escala.

---

## Comparativo

| Serviço | Gerencia servidor? |
