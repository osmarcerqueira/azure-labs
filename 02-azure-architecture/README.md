# Azure Architecture

## Regiões

As regiões representam áreas geográficas onde existem datacenters Microsoft.

Exemplo:

- Brazil South
- East US
- West Europe

---

## Zonas de Disponibilidade

São datacenters independentes dentro de uma região.

Objetivo:

Alta disponibilidade.

---

## Resource Groups

Servem para organizar recursos relacionados.

Exemplo:

RG-Web

- VM Ubuntu
- Storage
- Banco PostgreSQL

---

## Subscription

Controla:

- Cobrança
- Permissões
- Limites

---

## Management Groups

Organizam múltiplas subscriptions.
